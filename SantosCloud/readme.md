# Santos Cloud (UAS)



<br>

Santos cloud is social media that used for music producer and singer community "but this platform focused on underground music from indonesian only. it's kinda like soundcloud.

##### 

System flow :



* Login System

&#x09;1. Create Account (Register)

&#x09;2. Login

* Personal System

&#x09;1.Modify Account (CRUD -> change profile -> password -> bio ..etc)

&#x09;2.Post / modify Music (Single / album) "CRUD"

&#x09;3.Give a like and comment (on a single song / album)  "CRUD"

&#x09;4.Repost song (on a single song / album) "CRUD"

* Super User Do / (Admin authorize "role system")

&#x09;1.Ban user

&#x09;2.Delete comment

&#x09;3.Delete post (on a single song / album)
